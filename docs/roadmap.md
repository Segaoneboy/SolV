# Roadmap: SolV

## v1.0 - Hackaton MVP (current)
- [x]  **Full-Cycle Anchor Program**: On-chain logic for the entire voucher lifecycle: Minting, Escrow, and Atomic Redemption via PDAs.
- [x] **Unified RWA Marketplace**: High-performance Next.js platform for browsing, purchasing, and real-time asset tracking..
- [x] **Invisible Web3 (Privy)**: Seamless onboarding via social/email login with secure embedded wallets (no seed phrases required)..
- [x] **Merchant Dashboard**: Core interface for businesses to issue vouchers, monitor redemptions.

## v1.1 - Mainnet Alpha
- [ ] **Secondary Market**: A built-in DEX for users to trade or resell their unused vouchers.
- [ ] **Fiat On-ramp**: Integration with Stripe/MoonPay to allow credit card purchases directly into the SolV Vault.
- [ ] **Subscription Vouchers**: Recursive billing logic for monthly services (gyms, co-workings).
- [ ] **Solana Mobile Integration**: Native dApp development using **Solana Mobile Stack (SMS)** for secure, Seed-Vault protected merchant redemption flows.
- [ ] **Merchant Mobile SDK**: A lightweight QR-scanner app for physical stores to verify and "burn" vouchers.


## v1.2 - Mainnet Beta
- [ ] **Atomic Refunds**: Implementation of a 24-hour "cool-down" period for instant on-chain refunds.
- [ ] **Compression (pNFTs)**: Migrating UserVoucher PDAs to State Compression to support millions of vouchers at near-zero rent costs.

## v2.0 Ecosystem Growth
- [ ] **Cross-chain Vouchers**: Expansion to other SVM-based chains and L2s.
- [ ] **Institutional Partnerships**: API for major retail POS systems.
- [ ] **DAO Governance**: Community-led curation of verified merchants and protocol fee adjustments.
